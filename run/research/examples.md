# Examples

### x-01
objective: o-1
example: Hypothetical "ergative English": "He found me." but "Him traveled." — the lone traveler takes the object form, as the found person does.
why: Lets a novice feel S=O grouping using pronouns they already know. Breaks down because real ergative languages mark the agent (add -k), not just reshuffle he/him; use as a bridge only.
source: https://static.hlt.bme.hu/semantics/external/pages/morfológia_1/en.wikipedia.org/wiki/Ergative%e2%80%93absolutive_language.html

### x-02
objective: o-2
example: Basque minimal pair — "Martin etorri da" (Martin has arrived) vs "Martinek Diego ikusi du" (Martin has seen Diego). Martin gains -ek only when he acts on someone; Diego and arriving Martin both bare.
why: Same name in both sentences makes the ending visibly appear and disappear with transitivity. Ideal for a predict-the-suffix interaction.
source: https://en.wikipedia.org/wiki/Ergative–absolutive_alignment

### x-03
objective: o-3
example: Hindi-Urdu: "laṛkā pustak bēctā hai" (the boy sells a book; no marker) vs "laṛkē-nē pustak bēcī hai" (the boy has sold a book; ergative -nē).
why: Same participants, only aspect changes, and ergative marking switches on — the clearest split-ergativity demo.
source: https://en.wikipedia.org/wiki/Split_ergativity

### x-04
objective: o-2
example: Trap word: Basque "gizonak" = 'the man' (agent, ergative) or 'the men' (absolutive plural).
why: Shows why a reader can't just look for a final -k; useful as an "aha" or a footnote, but avoid it in early prediction puzzles.
source: https://en.wikipedia.org/wiki/Ergative–absolutive_alignment

### x-05
objective: o-2
example: Basque sentence set (translations as published). Same nouns in different roles. S, bare + da: "Umea etorri da." The child has come/arrived. / "Umea kalean erori da." The child has fallen in the street. / "Igela agertu da." The frog has appeared. A with -k, P bare + du: "Emakumeak gizona ikusi du." The woman has seen the man. / "Umeak ez du gizona ikusi." The child has not seen the man. / "Emakumeak liburua irakurri du." The woman has read the book. / "Zuk umea ikusi duzu kalean." You have seen the child in the street. (zu 'you' + -k.) Answer-key sentences: "Emakumea etorri da" (The woman has come) and "Gizonak emakumea ikusi du" (The man has seen the woman).
why: umea, emakumea and gizona each show up bare and with -k, so a reader can predict the ending from the role. The da/du auxiliary gives a second clue. Watch out: gizonak/umeak/emakumeak could also be read as absolutive plurals (c-06), so tell readers every noun here is singular.
source: https://ailo.adaptcentre.ie/wp-content/uploads/2020/04/Basqing-in-the-Sun.pdf

# Parking lot

- WALS: ergativity hotbeds are Australia and the Caucasus; almost absent from Africa, rare in Europe. (https://wals.info/chapter/98)
- Some linguists argue ergative patterns historically arose from passive constructions; others say there are multiple routes. (https://en.wikipedia.org/wiki/Ergative–absolutive_alignment)
- Georgian aorist: some intransitives (e.g. "sneeze", motion/weather verbs) take ergative subjects — split-S, not pure ergative. (https://en.wikipedia.org/wiki/Georgian_grammar)
- Hindi perfective: verb agreement flips to the object ('book', feminine) when the agent takes -nē. (https://en.wikipedia.org/wiki/Split_ergativity)
- Basque itself is debated: unergative verbs (e.g. 'work', 'laugh') take ergative subjects, so some call Basque split-S/active; not verified beyond search abstracts. (https://www.ehu.eus/HEB/wp-content/uploads/2012/06/LAKA-ERGATIVE-NEED-NOT-SPLIT-FINAL-OUP.pdf)

# Misconceptions

### m-01
objective: o-1
misconception: Grouping the lone sleeper with the doer ("subject") is just how logic or thought works, so every language must do it.
why_tempting: English and most familiar European languages do it, so "subject" feels like a fact about events rather than about grammar.
counter: c-03, c-04, c-07
source: model

### m-02
objective: o-2
misconception: An ergative sentence is really a passive ("Diego was seen by Martin"), because the agent is the marked one.
why_tempting: In English passives the agent is also demoted with extra marking ("by Martin"), and linguists do note the similarity and debate passive origins.
counter: c-04
source: https://en.wikipedia.org/wiki/Ergative–absolutive_alignment
note: Source: "Many linguists have noted grammatical similarity between ergative patterns and passives." The Basque sentence is still an ordinary active clause.

### m-03
objective: o-1
misconception: "Ergative" means verbs like break that can be used both ways ("The window broke"), so English is a bit ergative.
why_tempting: English grammar textbooks do call these "ergative verbs", so the novice who has met the term met it here.
counter: c-12
source: https://en.wikipedia.org/wiki/Ergative_verb

### m-04
objective: o-3
misconception: A language is either ergative or not, and Basque, Kurdish and Georgian are all simply ergative.
why_tempting: Popular summaries (including the original request) list them together as "ergative languages".
counter: c-08, c-09, c-10, c-11
source: model
